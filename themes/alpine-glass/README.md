# Alpine Glass

A native home layout built for this personal fork, based on the supplied alpine lock-screen reference: a translucent light clock behind the mountain ridge, a centered date/weather line, a circular Settings shortcut, three frosted viewing cards, and twelve compact dock icons. The profile selector is omitted. It uses a generated dusk landscape; it is not a pixel copy of the photographed TV.

**This requires the Alpine launcher build on `theme/alpine-glass`.** A JSON theme alone cannot add the depth clock, content reader or new dock layout to the upstream launcher. The original UI remains in `ClassicHomeActivity`; the previously installed Tide APK is retained privately for rollback.

This TV now uses direct Home ownership: Google TV’s launcher is disabled for user 0, the custom Home redirect helper is off, and `key_filter` is false with an empty `stock_home_redirect`. This prevents Home from passing through Google TV. Google’s native remote Settings/app-button handlers are also removed; the theme’s Settings shortcut remains available. The original no-filter native-handler mode can be restored with the local `work/direct-home/restore-native-handlers.sh`. The Home safety guards remain intact.

## Data and behavior

- The **Watch next** row mixes the latest eligible resume item with current app-published recommendations. It reads searchable Watch Next and preview-program rows with `android.permission.READ_TV_LISTINGS`, scanning up to 4,096 provider entries instead of stopping at the first 120. Browser entries, completed/30-day-old resume items, future live events and ended live programs are excluded. Each publisher appears once; discovery apps and items rotate every two minutes. Twitch uses only live-marked entries from its preview recommendation feed, never its Watch Next history or offline recommendations. No titles, progress or live status are invented.
- Feeds are re-read every 30 seconds only while Home is visible, immediately on return to Home, and after debounced provider notifications. Background timers stop when Home is hidden. Publishers still control when their own feeds change. Live thumbnails expire from the cache every two minutes. Updates are held while a card or the app library is focused, then applied when focus returns to the dock.
- Changed cards crossfade with Android's native Fade transition (240 ms), arriving artwork crossfades over 200 ms, and date/weather changes fade out/in over 100/160 ms. Unchanged content does not animate. The system animation switch and theme's reduced-motion/animations choices are respected.
- Program posters are loaded over HTTPS or through their publishing content provider. If an image cannot be read, the app's installed artwork remains visible.
- Weather uses Google’s official condition artwork stored locally, with separate clear/partly-cloudy day and night icons and rain, snow and storm icons. Weather comes from [Open-Meteo](https://open-meteo.com/), cached for 30 minutes and refreshed only while Home is visible. Attribution appears in the Apps panel. The selected location lives in a private `alpine/private.json` under the launcher's external-files directory; coordinates are not included in the public theme.
- The landscape retains the original wallpaper’s saturation and warmth. Solar lighting moves smoothly through dawn, warm morning, daylight, golden hour, twilight and night using locally calculated sunrise and sunset at the private weather location. It updates once per minute while Home is visible and recalculates for date/time-zone changes; there are no added network requests. Without a configured location it uses the existing 07:00/18:30 defaults. The scene, mountain occlusion and frosted containers share the same lighting, with a single cached blur. Card and dock border opacity is reduced to 7% while keeping the original 1.25-pixel stroke width. The top Settings shortcut has no border. Focus combines the existing scale with a restrained exterior glow, crossfading over 180 ms. There is no focus border or moving outline. The halo also covers Now Playing targets and the Apps panel, tracking child scaling and scroll in the same window coordinates. App-panel scrolling keeps the focused icon and its label visible, and dock end tiles can scale beyond the inner padding; it uses analytical rounded light layers without live blur or idle redraws. The clock uses its own tinted glass fill and a foreground clipping path matched to this particular mountain silhouette. No video, live wallpaper or per-frame blur is used.
- Native Android D-pad focus links move between dock, cards and top Settings in rows and hold at the horizontal ends; system navigation sound effects are enabled. The last dock focus is retained. At the tested 1920×1080 layout, twelve 110-pixel square slots have equal 146-pixel outer margins. The dock panel wraps the icon group with 16 dp of inner padding on each side. The twelve slots are ten installed apps, Settings and All apps. Installed brand icons are used; missing reference apps are not added.

## Top-right controls

The top row includes the standard theme’s Inputs and Network controls beside Settings. Network shows Ethernet, the Wi-Fi name when Android exposes it, or Offline. Its label follows connectivity callbacks while Home is visible; it does not poll. It opens the same network settings route as the standard theme.

Inputs uses the standard `popup_inputs` / `item_input` dropdown under its pill, with the original input enumeration, connection indicators, custom/CEC device names, Live TV row and optional More inputs folding. Its opaque stock panel is replaced by this theme’s cached, sun-graded wallpaper blur and translucent glass tint. Switching remains scoped to the configured TV player before generic fallback, with the same vendor source mapping behavior as the standard launcher. No input is switched just by opening the menu.

## Now Playing

A compact frosted widget at the top left displays the highest-priority real media session: playing first, then loading, then paused media available to resume. Stopped/error sessions and empty metadata stay hidden. It shows artwork, title, artist and app/state, with Open player, Play/Pause and supported Next controls. The top row uses native D-pad focus links; updates fade gently and preserve the centered clock/date.

The widget observes MediaSessionManager/controller callbacks only while Home is visible. It does not poll or start playback on its own. It requires approval for the dedicated `.MediaAccess` notification-listener component, configured with an empty default filter and every notification category disabled. The service reads no notifications and does not revive Home/key helpers. Google TV remains disabled. Artwork can use the media app’s supplied HTTPS/content URI.

The local session saved the previous installed APK and provides `work/now-playing/remove-widget.sh` to remove media access and restore it while keeping direct Home. API references: [MediaSessionManager](https://developer.android.com/reference/android/media/session/MediaSessionManager) and [notification listener filter types](https://developer.android.com/reference/android/service/notification/NotificationListenerService#META_DATA_DEFAULT_FILTER_TYPES).

## Local typefaces

The clock was reverted to the earlier light treatment at the user’s request. It loads the private variable SF Pro face with width 47, weight 270.325 and optical size 28; there is no additional horizontal text scaling. The private static Light face is the fallback. The clock tint is roughly 40% opaque, with a richer blurred scene showing through. Its blur uses a separate 1.5× saturation treatment at 82% opacity, retaining the sun-timed lighting. Overlapping glyph contours are combined before drawing the glass rim, preventing internal seams in 6 and 9 without changing the font or dimensions.

Optional typefaces are loaded from `alpine/font-clock.ttf` (or `alpine/font-clock.otf`), `alpine/font-text.otf` and `alpine/font-medium.otf` under the launcher's external-files directory. These are local files, not APK resources. Without them, Android's built-in sans-serif families are used. No Apple font files are included in this repository, the APK or GitHub; their published [licence](https://developer.apple.com/fonts/) still restricts non-Apple use even when private. No system font is replaced.

## Customize

`wallpaper.jpg` is the original 1920×1080 landscape, with sun-timed lighting applied at draw time. The palette and interpolation anchors are in `AlpineSolarLight.java`; sunrise and sunset come from the existing offline `Sun` calculation. The clock's depth clipping follows this image's ridge: changing the wallpaper also needs a matching clipping path in `AlpineArt.java`. The glass style and twelve-icon layout are native code. To rearrange the dock, hold OK on a dock app and choose **Move**, or open **All apps → Edit dock**. Holding OK on Settings or All apps starts moving that shortcut directly. Left/Right moves the selected tile, OK saves, and Back cancels. Settings and All apps can be moved too. To pin or unpin an app, hold OK on it in **All apps** and choose **Add to dock** or **Remove from dock**. A full dock asks which app to replace; the replaced app remains in All apps. Holding OK on a dock app also offers **Remove from dock**. Removed apps leave a subtle **+** place; select it to choose an app for that exact place. Settings and All apps remain available. Both membership and order survive restarts and updates; your existing order stays unchanged until you save an edit. The priority list in `MainActivity.buildDock` supplies the initial order, filtered to installed apps.

On an already configured TV running this build, apply the appearance with:

```sh
TV_HOST=<tv ip> tools/theme.sh themes/alpine-glass
```

The local session's `work/alpine/build-and-install.sh` and `work/alpine/restore-tide.sh` rebuild/update this configured TV or restore the saved Tide build. Those scripts, device backups, private fonts and weather settings stay local. The standard upstream handover installer still requires direct Home ownership; its guards must remain intact.

Artwork provenance and the exact generation prompt are in [CREDITS.md](CREDITS.md) and [PROMPT.txt](PROMPT.txt). Local screenshots are from the real TV; viewing titles in a screenshot may be private and should be reviewed before publication.
