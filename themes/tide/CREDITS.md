# Artwork

`wallpaper.jpg` is original AI-generated artwork created for this theme on 26 October 2026 using the built-in OpenAI image generation tool. It depicts a fictional aerial coastline and is not a photograph of a named location. No third-party stock image or reference photograph was used.

The original generated PNG is kept privately in the local session's `work/tide/` folder. The deployable JPEG is resized to 1920×1080 and compressed for the TV. The exact generation prompt is in `PROMPT.txt`.
