# Credits

The wallpaper was generated with the built-in OpenAI image-generation tool using the user-supplied TV photograph as a composition reference. It depicts a fictional alpine dusk scene. The TV frame, room, interface and reflections were excluded from the generated wallpaper. The exact prompt is in PROMPT.txt.

The material blur, clock, foreground depth clipping, interface and navigation are rendered by native Android code. Installed apps supply their own logos, content and posters. Weather data is from Open-Meteo under CC BY 4.0; see https://open-meteo.com/ and https://creativecommons.org/licenses/by/4.0/.

Apple font files are private local assets and are not redistributed here. Open-source launcher code remains under the repository's MIT licence.

Weather artwork is Google’s official Weather condition icon set, downloaded from `maps.gstatic.com/weather/v1/`, resized to 64 pixels and losslessly encoded as WebP for local rendering. Source: https://developers.google.com/maps/documentation/weather/weather-condition-icons . These Google assets are distinct from the repository’s MIT-licensed code.
